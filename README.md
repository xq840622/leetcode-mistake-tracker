# LeetCode 错题本 (LeetCode Mistake Tracker)

在 VSCode 里完成 leetcode.cn 刷题全流程：打开题目、编辑器内提交、断点调试、执行回放、错题自动记录、AI 错误归因、错题 markdown 笔记、题单管理——从找题到复盘归档，全程不用切出 VSCode。

面向 Python3 刷题（题目文件兼容 labuladong 插件格式，旧文件原地可用）。**核心功能零依赖、数据纯本地。**

## ✨ Features

1. 📥 **打开题目即本地文件** — 全题库 4000+ 题搜索（编号/题名/slug），点题生成含中文题面 + python3 模板 + 官方示例用例的本地文件；会员题自动带 Cookie 拉取
2. 🚀 **编辑器内一键提交** — REST 直连 leetcode.cn，自动判定 AC/WA 并入错题库，不用切浏览器
3. 🐞 **断点调试** — 断点直接下在题目文件，`@lcpr case` 用例自动喂参，链表/树自动构建
4. 🔍 **执行回放** — Python Tutor 式逐步动画：语法高亮、变量类型徽章、变更/新增闪动、自动播放；每个用例块上方各有独立回放入口，想用哪个用例复现就点哪个
5. ↩️ **重置代码区** — 代码区一键恢复初始模板，题干与用例不动，Cmd+Z 可撤销
6. 🤖 **AI 错误归因** — 提交失败自动归因（语法/边界/复杂度/思路，带回错用例代入与 AC 代码对照），支持批量补齐与自定义提示词
7. 📝 **错题 md 笔记** — 导出到自选的普通目录，纯 markdown 零门槛：VSCode 里直接预览（`Cmd+Shift+V`），也可随时用 Obsidian 等任意笔记软件打开同一目录；frontmatter 元数据 + AI 归因与提交时间线自动更新，**手写复盘区永不被覆盖**
8. 📚 **题单管理** — 我的题单（LeetCode 账号收藏夹/自建题单，自动同步）/ 收藏的题单 / 导入题单（题号、题名、slug、URL、markdown 表格、JSON 混贴全识别）/ 热题 100 / 难度分类 / 全部题目
9. 📊 **概览与仪表盘** — 错题率、Cookie 登录态剩余天数、最近错题一目了然；仪表盘支持按题单切换统计口径，进度、错题率、错误类型分布、最近提交跟着口径重算

## 🚀 Quick Start

1. 安装后在活动栏点 📖 进入「LeetCode 错题本」侧边栏（概览 / 题单 / 记录与整理 / 设置 四个视图）
2. **（可选但推荐）配置 Cookie**：浏览器登录 leetcode.cn → `F12` → Network → 复制任一请求的 **cookie 整行** → 概览视图「Cookie 登录态」一行点进去粘贴。不登录也能用：打开非会员题、写代码、调试、回放、手动记录；**提交代码、同步提交记录、拉取会员题面**需要 Cookie（约每月续期一次，概览会显示剩余天数）
3. 题单或命令面板「错题本: 打开题目」找题 → 写代码 → 编辑器右上角 🚀 提交，自动判定入库
4. **（可选）配置 AI 归因**：侧边栏「设置」点「AI 归因」，填 OpenAI 兼容端点 / Key / 模型（默认智谱端点）。之后失败提交自动归因并写错题 md 笔记

## 📖 Usage

### 刷题工作流

1. **找题**：题单视图点题即生成或打开本地文件（默认 `~/leetcode/editor/cn/1.two-sum.py`）
2. **写代码**：模板、题面、官方用例都在一个文件里；写乱了点 ↩️ **重置** 恢复初始模板
3. **验证**：编辑器右上角图标与代码区上方悬浮按钮（CodeLens）——🚀 提交 / ↩️ 重置 / 🐞 断点调试 / 🔍 执行回放；每个 `@lcpr case` 用例块上方各有一个 🔍回放 case N，单独复现某个用例
4. **入库**：提交自动判定 AC/WA 入错题库；提交失败且已配置 AI → 自动归因并写错题 md；未配置 AI → 只记错题集
5. **复盘**：「记录与整理」视图可同步提交记录、批量 AI 归因、导出错题 md；「概览」看错题率与最近错题，「仪表盘」按题单口径看统计

### 题单：三层来源

- **我的题单**：LeetCode 账号里的收藏夹 / VIP 自建题单，自动同步——网页端改了这边跟着变（需 Cookie）
- **收藏的题单**：收藏的他人/官方题单，同样自动同步（需 Cookie）
- **导入题单**：本地导入，两步引导（选内容来源：剪贴板带识别预览 / 文件 → 命名）；题号、题名、slug、URL、markdown 表格、JSON 混贴全识别

### AI 归因与自定义提示词

归因输出四要素：错误类别（语法/边界/复杂度/思路/其他）、一句话诊断、一句话修复方向、对照 AC 代码的差异定位。提示词可通过 `lmt.aiPrompt` 完全自定义：内置默认包含五类错误的判定顺序、WA 反例代入法、对照 AC 代码 diff 归因、boundary/logic 判别线等；点侧边栏「设置 → AI 提示词」可复制默认全文，改完保存即生效。

### 错题 md 笔记

- 一题一文件（`题号.题名.md`），存于你指定的普通目录；导出成功通知带「预览」（VSCode 内置 markdown 预览）与「打开目录」
- frontmatter 含 `qid/slug/difficulty/status/attempts/errorTypes` 等元数据；想按错误类型筛题，在目录里全局搜索 `errorTypes` 即可
- `<!--lmt:generated-->` 标记块内（AI 归因、提交时间线）每次导出自动更新；标记块外（复盘区）永远保留手写内容
- 与笔记软件解耦：目录里就是普通 md 文件，想用 Obsidian 时把该目录作为 vault 打开即可，无需迁移

## ⚙️ Extension Settings

| 设置 | 默认 | 说明 |
|---|---|---|
| `lmt.problemsDir` | `""`（→ `~/leetcode/editor/cn`） | 题目文件根目录 |
| `lmt.leetcodeCookie` | `""` | leetcode.cn Cookie（建议用「一键续期」配置） |
| `lmt.aiBaseUrl` | 智谱端点 | OpenAI 兼容 API 端点 |
| `lmt.aiApiKey` / `lmt.aiModel` | `""` | AI 归因密钥与模型 |
| `lmt.aiPrompt` | `""`（内置默认） | 自定义 AI 归因 system 提示词，整体替换默认；仍须要求模型只输出 `{"type","summary","fixHint"}` JSON |
| `lmt.notesDirPath` | `""` | 错题 md 笔记目录；留空则首次导出时弹窗选择并记住 |
| `lmt.autoSyncMinutes` | `15` | 自动同步间隔（0 关闭） |
| `lmt.autoAnalyzePerSync` | `5` | 每轮同步最多自动归因几题 |

## 🔒 Privacy & Data

- **数据纯本地**：所有记录存于本机 VSCode globalStorage（纯本地 JSON），题目文件与错题笔记存于你指定的目录；不经过任何第三方服务器
- **Cookie 只在本机直接请求 `leetcode.cn` 时使用**
- **AI 归因会把当前代码与题目信息发送给你配置的 API 端点**；不配置则该功能不可用，其余功能不受影响
- **插件不内置、不分发任何付费/企业题单内容**：「我的题单」「收藏的题单」由你自己的 leetcode.cn 账号实时拉取，仅本人可见、缓存在本机；唯一内置数据是官方公开「热题 100」的题号/题名索引（用于离线展示）
